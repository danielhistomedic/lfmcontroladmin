# UI/UX web — LFM Control
Leer controlesforms.md y comparar con páginas reales del portal, sus estilos y componentes. No usar formularios VB.NET como implementación web.
Mantener navegación y jerarquía del módulo. Reutilizar plantillas, iconos, alertas, modales y bibliotecas instaladas.
Distinguir acción principal, mensajes contextuales y confirmaciones destructivas. Conservar campos, permisos y estatus de negocio.
Diseñar formularios con etiquetas, foco y teclado; considerar móvil y tablas anchas. No depender solo de color.
En tablas conservar filtros, selección según operación, paginación y orden por fecha real. Indicar moneda/unidad y totales sin mezclar monedas.
Mostrar carga, vacío, error y recuperación sin porcentajes falsos. Mantener valores ante error y devolver controles a estado usable.
No modificar SQL ni reglas comerciales para una corrección visual. Verificar en navegador autorizado cuando exista el portal; informar si solo se revisó código.
