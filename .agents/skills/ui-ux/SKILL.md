# ui-ux — lfm_admin
Leer [instructions.md](instructions.md) completo y aplicar [AGENTS.md](../../../AGENTS.md) antes de trabajar.
Leer las reglas aplicables enlazadas desde AGENTS.md. Verificar recursos en el portal real y realizar las fases secuencialmente cuando no exista delegación autorizada.
Para gráficas Apache ECharts aplicar también [el perfil especializado](../echarts/SKILL.md).

Para presentación de módulos actuales y nuevos aplicar la [fuente estándar Arial, Helvetica, sans-serif](../../rules/controlesforms.md#tipografia-estandar).

Para formularios y presentación de módulos actuales o nuevos, incluido Login, aplicar el [estándar obligatorio de labels](../../rules/controlesforms.md#labels-estandar).

Para campos de módulos actuales y nuevos, incluido Login, aplicar el [estándar de input, textarea y select](../../rules/controlesforms.md#campos-estandar): fondo blanco y borde neutro sin sombra en reposo; borde azul claro y sombra suave solo con foco, también en Select2.
